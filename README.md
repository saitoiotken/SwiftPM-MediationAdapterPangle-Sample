# FluctSDKMediationAdapterPangle

## Introduction

Pangle custom event for FluctSDK mediation, distributed via [Swift Package Manager](https://swift.org/package-manager/).

## Requirements

- iOS 12.0 or later

## Installation

Add this package to your project and link the `FluctSDKMediationAdapterPangle` product.
FluctSDK and Pangle SDK are resolved as dependencies of this package.

Add `-ObjC` to **Other Linker Flags** of your app target.
